# 🥊 MMA LIFE DYNASTY

Uma simulação de carreira em MMA com sistema de dinastia, treinamento, combates e construção de legado.

## 🎮 Como Jogar

1. Abra `index.html` no navegador
2. Crie seu lutador
3. Treine, lute e construa sua carreira
4. Crie uma dinastia com seus filhos

## 📁 Estrutura do Projeto
## ✨ Features

- ✅ Criação de lutador customizável
- ✅ Sistema de treinamento com múltiplos estilos
- ✅ Simulação de combates
- ✅ Progressão de carreira
- ✅ Sistema de família e herança
- ✅ Gestão de finances
- ✅ Notícias e popularidade
- ✅ Sistema de contratos
- ✅ Ranking de lutadores
- ✅ Save/Load Game

## 🎯 Objetivos do Jogo

- Alcançar o nível Elite
- Vencer campeonatos
- Construir uma dinastia com seus filhos
- Ficar rico e famoso

## 📊 Atributos

- **Strength** - Força nos golpes
- **Speed** - Velocidade de movimento
- **Stamina** - Resistência
- **Technique** - Habilidade técnica
- **Defense** - Capacidade defensiva
- **Chin** - Resistência a golpes
- **Wrestling** - Lutas
- **Striking** - Golpes
